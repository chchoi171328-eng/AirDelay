# Topics — 묶음 · 사이트 연결 · 주제 후보 · 확정 정책

## 1. 묶음 (이 두 값만 사용)

| 값 | 표시명 | 성격 | 기본 cover |
|---|---|---|---|
| `claim` | 보상·청구 | 보상 기준, 항공사 대응, 청구와 공동소송 | `/images/blog/claim.jpg` |
| `aviation` | 항공 상식 | 지연 코드, 항공 기상, 정비, 관제·공항, 연결·승무원 등 업계 지식 | `/images/blog/aviation.jpg` |

- 글은 **하나의 묶음**만 갖는다. 애매하면 독자가 들어오는 입구(검색어)로 정한다
  (예: "METAR 읽는 법" → `aviation`, "기상 악화 거절 대응" → `claim`).
- 목록 페이지(`/guide`)는 묶음별로 나뉘어 표시되고, 글이 없는 묶음은 숨겨진다.

## 2. 사이트 안내 페이지 (기둥)

가이드 글은 아래 페이지의 내용을 펼친 가지다. 페이지 말미의 「함께 보면 좋은 자료」에 묶음별로 자동 연결된다.

| 페이지 | 주소 | 담고 있는 것 |
|---|---|---|
| 보상 기준 | `/services` | 노선별 적용 기준(`#rules`), 지연 보상(`#delay`), 결항 보상(`#cancel`), 보상이 어려운 경우(`#exceptions`), 청구 기한(`#deadline`) |
| 진행 절차와 비용 | `/process` | 5단계 절차(`#steps`), 공동소송 차수·기준(`#group`), 비용(`#cost`) |
| 자주 묻는 질문 | `/faq` | 비용·접수·진행·보상 기준·공동소송 질문 |
| 법인 소개 | `/about` | 한국·영국 협업 방식(`#collab`), 사무소·연락처(`#contact`) |

본문 안 링크는 위 주소와 실제로 있는 가이드(`content/blog/*.md`)에만 건다. 아직 없는 글은 링크 대신
`<!-- TODO: 내부 링크 {주제} -->` 주석만 남긴다.

## 3. 주제 후보 (확정 목록 아님 — 1단계 중복 확인 후 사용)

### claim — 보상·청구
- 비행기 3시간 지연, 보상받을 수 있을까 — 노선별 기준 한눈에 보기
- 인천→파리는 안 되고 파리→인천은 된다? 같은 노선, 다른 보상 기준
- EU261 보상금 €250·400·600, 비행거리로 계산하는 법
- 대한항공·아시아나 유럽 노선 지연, 어떤 기준이 적용될까 (항공사 이름이 들어간 글은 사실만)
- 경유편이 늦어 연결편을 놓쳤다면, 지연 시간은 어떻게 셀까
- 코드셰어 항공편 지연, 어느 항공사에 청구할까
- 결항 통보, 출발 14일 전후로 달라지는 보상
- 브렉시트 이후 영국 노선 — UK261 정리
- 국제선 지연·결항과 몬트리올 협약 — 정액이 없을 때 청구하는 손해
- "기상 악화라 보상이 어렵습니다" — 항공사 거절 사유, 그대로 믿어도 될까
- 기체 정비·승무원 문제로 늦어졌다면 보상 대상일까
- 항공사가 바우처를 제안할 때, 받기 전에 확인할 것
- 항공사가 거절하면? 공동소송으로 함께 청구하는 방법
- 가족 여행 중 지연, 함께 탄 가족 모두 청구할 수 있을까
- 여행사·예약 사이트에서 산 항공권, 청구는 누가 할까
- 탑승권이 없어도 청구할 수 있을까
- 지연·결항 직후 공항에서 챙겨야 할 증거 5가지
- 항공 지연 보상 청구 기한

### aviation — 항공 상식
- 항공 지연 용어 사전 (용어 사전형, 계속 갱신)
- 항공사 지연 사유 코드, 무엇을 말해 줄까 — IATA 지연 코드 읽는 법
- "앞 비행편이 늦어서" — 연결(로테이션) 지연이란
- 그날 공항 날씨는 정말 나빴을까 — METAR·TAF 읽는 법
- 항공기 정비의 종류 — 일상 점검부터 C 체크, 그리고 MEL
- AOG(지상 정지)는 왜 결항으로 이어질까
- 항공사가 말하는 '관제 지연' — 슬롯(CTOT)과 흐름 관리
- 도착 시각은 언제일까 — 착륙, 블록 인, 문이 열리는 순간 (claim과 잇는 글)
- 환승편을 놓쳤다면 — 최소 연결 시간(MCT)
- 승무원 근무시간 제한 때문에 출발하지 못했다면
- 밤에 결항이 많은 이유 — 공항 운항 제한 시간(커퓨)
- 겨울철 지연 — 제빙(디아이싱) 작업과 대기 순서
- 회항(다이버전)과 지연 보상

용어 사전형의 분야 구성 예:
- **운항 시각** — STD/STA, ETD/ETA, ATD/ATA, 블록 아웃·블록 인, 도어 클로즈·오픈
- **지연 코드** — IATA 지연 코드, 1차 지연, 연결(로테이션) 지연
- **항공 기상** — METAR, TAF, SIGMET, 저시정 운항(CAT II/III), 제빙
- **정비** — 라인 정비, A·C 체크, MEL, AOG
- **관제·공항** — CTOT·슬롯, 흐름 관리(ATFM), 커퓨, 회항
- **연결·승무원** — MCT, 승무원 근무시간 제한

### 우선순위
1. 검색 수요가 크고 사이트 전환과 바로 이어지는 claim 글 (3시간 지연, 금액, 거절 대응, 공동소송)
2. 거절 사유를 해석하는 aviation 글 (지연 코드, 기상, 정비) — 경쟁 콘텐츠가 적고 전문성이 드러난다
3. 용어 사전 — aviation 글이 몇 편 생긴 뒤 허브로

## 4. 사이트 확정 정책 (글에 쓸 때 이 문구 그대로)

**비용**
- 접수·보상 가능 여부 판단: 비용 없음
- 항공사 청구: 보상금을 받은 경우에만 성공보수 25%(부가세 포함)
- 공동소송: 참여에 동의할 때 소송 진행비 1인 1만 원 + 판결금·합의금을 받은 경우 성공보수 25%(부가세 포함). 소송으로 가도 요율은 같다
- 성공보수는 항공사로부터 실제로 받은 금액을 기준으로 계산
- 소송 진행비는 인지대·송달료 등에 쓰이는 정액이며, 법인이 소송을 제기하지 않게 되면 돌려준다

**연락·절차**
- 접수 후 **영업일 기준 2일 이내** 연락 (보상 가능 여부 안내 또는 필요한 내용 문의)
- 절차: 사건 접수 → 보상 가능 여부 판단 → 항공사 청구 → (항공사가 거절하면) 공동소송 → 보상금 수령
- 고객 창구는 한국 법인. 유럽 노선 청구는 영국 변호사, 그 밖의 노선은 한국 변호사가 맡고, 소송은 유럽 노선도 한국 법인이 한국 법원에서 진행
- 고객이 법원에 나올 일은 없다

**공동소송**
- 같은 항공사 사건을 **운항일 기준 6개월 단위**로 모은다: 1~6월 운항분은 상반기, 7~12월 운항분은 하반기 차수
- 6월 말·12월 말 마감 → 마감 후 항공사별 진행 여부를 한꺼번에 안내 → 안내받은 날부터 1개월 안에 동의 → 8월·다음 해 2월 중 소장 접수
- 항공사가 기한 안에 답하지 않으면 거절로 보고 같은 차수에 포함
- 같은 항공사 사건이 너무 적으면 다음 차수로 한 번 넘기고, 그래도 어려우면 미리 알린다
- 소송에서는 한국 법원이 한국법에 따라 판단하며, 재판부마다 인정 금액이 달라 EU 규정 금액보다 적을 수 있다 — **예상 금액은 말하지 않는다**

**쓰지 않는 말**: 무료 상담 / 변협 인증 / 48시간 이내 / 공동소송 최소 인원 / 패소 시 비용·실비 / 소비자분쟁해결기준을 근거로 한 보상 기준
