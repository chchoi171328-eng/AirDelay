# Topics — 묶음 · 사이트 연결 · 주제 후보 · 확정 정책

## 1. 묶음 (이 두 값만 사용)

| 값 | 표시명 | 성격 | 기본 cover |
|---|---|---|---|
| `claim` | 보상·청구 | 보상 기준, 항공사 대응, 청구와 공동소송 | `/images/blog/claim.jpg` |
| `aviation` | 항공 상식 | 지연 코드, 항공 기상, 정비, 관제·공항, 연결·승무원 등 업계 지식 | `/images/blog/aviation.jpg` |

- 글은 **하나의 묶음**만 갖는다. 애매하면 독자가 들어오는 입구(검색어)로 정한다
  (예: "METAR 읽는 법" → `aviation`, "기상 악화 거절 대응" → `claim`).
- 목록 페이지(`/guide`)는 묶음별로 나뉘어 표시되고, 글이 없는 묶음은 숨겨진다.

## 2. 사이트 안내 페이지 (기둥)

가이드 글은 아래 페이지의 내용을 펼친 가지다. 글 말미에 자동으로 붙는 링크는 없으므로, 필요하면 본문 문장 속에 자연스럽게 링크를 건다
(예: "노선별 기준은 [보상 기준](/services#rules)에 정리해 두었습니다.").

| 페이지 | 주소 | 담고 있는 것 |
|---|---|---|
| 보상 기준 | `/services` | 노선별 적용 기준(`#rules`), 지연 보상(`#delay`), 결항 보상(`#cancel`), 보상이 어려운 경우(`#exceptions`), 청구 기한(`#deadline`) |
| 진행 절차와 비용 | `/process` | 5단계 절차(`#steps`), 공동소송 차수·기준(`#group`), 비용(`#cost`) |
| 자주 묻는 질문 | `/faq` | 비용·접수·진행·보상 기준·공동소송 질문 |
| 운영 법인 소개 | `/about` | 운영 법인(`#mission`), 한국·영국 협업 방식(`#collab`), 사무소·연락처(`#contact`) |

본문 안 링크는 위 주소와 실제로 있는 가이드(`content/blog/*.md`)에만 건다. 아직 없는 글은 링크 대신
`<!-- TODO: 내부 링크 {주제} -->` 주석만 남긴다.

## 3. 글 목록 (2026년 10월 정리)

한 줄 = 한 편. 각 글은 질문 하나에 답하는 짧은 글(2,000~3,500자)로 쓴다. ★는 먼저 쓸 글이다.
1단계 중복 확인 때 이 목록과 `content/blog/`를 함께 본다. 목록에 없는 주제를 새로 쓸 때도 기존 글과 겹치지 않게 좁힌다.

|---|---|---|

항공 기상(METAR·TAF·SIGMET·저시정 운항·제빙) / 정비(라인 정비·A·C 체크·MEL·AOG) / 관제·공항(CTOT·슬롯·ATFM·커퓨·회항) / 연결·승무원(MCT·근무시간 제한)

### 쓰지 않기로 한 주제
- 소비자분쟁해결기준으로 보는 보상 기준 (강제력이 없고 법원도 따르지 않음)
- 국내선 지연 배상 기준만 다루는 글 (필요하면 12번 안에서 상법을 짧게)
- "최대 600유로 받는 법"처럼 금액을 보장하는 듯한 제목

### 쓰는 순서
1. claim ★1~★5 — 검색 수요가 크고 사이트 전환과 바로 이어진다
2. aviation ★1~★3 — 항공사 거절 사유를 해석하는 글. 경쟁 콘텐츠가 적고 전문성이 드러난다
3. 나머지 claim → 나머지 aviation → 용어 사전(허브)


## 4. 사이트 확정 정책 (글에 쓸 때 이 문구 그대로)

**브랜드 이름** (2026년 10월 사용자 확정)
- 서비스 이름은 **에어리걸클레임**(영문 AirLegal Claim). 항상 붙여 쓴다 — "에어리걸 클레임" 띄어쓰기, "에어리걸" 단독 약칭 금지
- 운영 주체 문구: "에어리걸클레임은 법무법인 명(SOL & LUNA)이 운영하는 항공지연·결항 보상 전문 서비스입니다."
- 문장마다 서비스를 가리키면 에어리걸클레임, 법인·변호사·계약 주체(위임계약, 소송 원고 대리, 작성자 표시)를 가리키면 법무법인 명
- 가이드 본문에는 서비스 이름을 쓸 일이 거의 없다(접수 안내는 맺음 상자가 맡는다). 작성자(`author`)는 법무법인 명 그대로
- "전문"은 써도 된다. "변협 인증", "변협 등록 전문분야", "인증 전문변호사"처럼 변협 인증·등록으로 읽히는 표현은 금지
- 메인 사이트(sllaw.co.kr·lsfp.co.kr)로 가는 링크는 넣지 않는다. 운영 법인 소개는 이 사이트의 `/about`

**비용**
- 접수·보상 가능 여부 판단: 비용 없음
- 항공사 청구: 보상금을 받은 경우에만 성공보수 25%(부가세 포함)
- 공동소송: 참여에 동의할 때 소송마다 진행비 1인 1만 원 + 판결금·합의금을 받은 경우 성공보수 25%(부가세 포함). 소송으로 가도 요율은 같다
- 소송 진행비는 소송(항공사)마다 낸다. 항공사가 달라 소송이 둘 이상이면 소송별로 1인 1만 원 (2026년 10월 사용자 확정)
- 성공보수는 항공사로부터 실제로 받은 금액을 기준으로 계산
- 소송 진행비는 인지대·송달료 등에 쓰이는 정액이며, 법인이 소송을 제기하지 않게 되면 돌려준다

**연락·절차**
- 접수 후 **영업일 기준 2일 이내** 연락 (보상 가능 여부 안내 또는 필요한 내용 문의)
- 절차: 사건 접수 → 보상 가능 여부 판단 → 항공사 청구 → (항공사가 거절하면) 공동소송 → 보상금 수령
- 고객 창구는 한국 법인. 유럽 노선 청구는 영국 변호사, 그 밖의 노선은 한국 변호사가 맡고, 소송은 유럽 노선도 한국 법인이 한국 법원에서 진행
- 고객이 법원에 나올 일은 없다

**필요서류** (2026년 10월 사용자 확정)
- 안내하는 필요서류는 항공권(e-티켓)·탑승권과 **항공사가 발급한 지연확인서**(결항이면 결항 확인서나 결항 안내 문자·이메일)
- 지연을 보여 주는 자료는 지연확인서로 안내한다. 공항 카운터나 항공사 고객센터·홈페이지에서 요청해 받고, 발급 방법은 항공사마다 다르다
- 숙박비·식비·교통비 같은 실비 영수증은 필요서류나 '챙길 자료'로 안내하지 않는다 — 국내에서는 실비가 인정되는 경우가 거의 없다. EU261 제9조 돌봄 의무 같은 권리 설명은 쓸 수 있지만 영수증 보관을 권하지 않는다

**공동소송**
- 같은 항공사 사건을 **운항일 기준 6개월 단위**로 모은다: 1~6월 운항분은 상반기, 7~12월 운항분은 하반기 차수
- 접수 마감은 운항 기간이 끝나고 2개월 뒤: 상반기 8월 말, 하반기 다음 해 2월 말
- 항공사 청구서의 답변 기한은 1개월. 기한 안에 답하지 않으면 거절로 보고 같은 차수에 포함
- 9월 말·3월 말까지 항공사 청구가 마무리된 사건을 모아 → 10월 초·4월 초 항공사별 진행 여부를 한꺼번에 안내 → 안내받은 날부터 1개월 안에 동의 → 11월·5월 중 소장 접수
- 접수 마감 뒤 접수분이나 9월 말·3월 말까지 청구가 끝나지 않은 사건은 다음 차수에 포함
- 같은 항공사 사건이 너무 적으면 다음 차수로 한 번 넘기고, 그래도 어려우면 미리 알린다
- 소송에서는 한국 법원이 한국법에 따라 판단할 수 있고, 재판부마다 인정 금액이 달라 EU 규정 금액보다 적을 수 있다 — **예상 금액은 말하지 않는다**. 한국 법원의 EU 규정 적용 여부는 단정하지 않는다
- EU261·UK261 금액은 항공사에 청구할 때의 규정 기준으로만 쓴다 (보상 기준 페이지 금액표 아래, 가이드 글 법률 정보 안내에 같은 문장)

**쓰지 않는 말**: 무료 상담 / 변협 인증 / 48시간 이내 / 공동소송 최소 인원 / 패소 시 비용·실비 / 소비자분쟁해결기준을 근거로 한 보상 기준
